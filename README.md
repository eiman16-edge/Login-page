# Login & Registration Interface
A lightweight, responsive login and registration interface built with plain
HTML, CSS, and JavaScript. The project is designed as a simple front-end
starting point for authentication flows.

## How It Works

- The **Login** and **Register** tabs show and hide their corresponding forms.
- Password fields can be switched between masked and visible text using the
  eye button.
- Registration fields are validated as the user types:
  - Email must follow a basic email format.
  - Password must contain at least six characters.
  - Confirmation must match the password.
- Invalid fields receive a red error state. A successful form submission
  currently displays a browser alert.
  
  Live demo : https://eiman16-edge.github.io/Login-page/
